# WRASAL Visual DNA reference board specification

A reference board should contain one independently rendered specimen per card in `WRASAL_SPECIMEN_INDEX_v001.json`, arranged as ten labeled evidence plates. Do not use a decorative collage. Each plate should preserve its own caption, ID, mode, and audit score. Generate the board only after rendering the specimens; this repository intentionally stores the reproducible briefs and machine-readable index rather than unverified AI output.
